# cursor-plugins

Cursor / VS Code extensions maintained in this repository.

## Packages

- **[cursor-context](./cursor-context/)** — Activity bar panel to browse Cursor rules, commands, `.cursor/agents` prompts, skills, hooks, MCP entries, and `AGENTS.md`; open files and copy `@` path references for Agent chat.
- **[just-run](./just-run/)** — Activity bar panel to list and run [just](https://github.com/casey/just) recipes from the workspace `justfile` / `Justfile`.

Development, packaging, and install instructions for each extension live in that package’s README.
